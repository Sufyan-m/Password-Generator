
A simple Python password generator that creates random passwords based on the length entered by the user.

Features
🔤 Lowercase letters
🔠 Uppercase letters
🔢 Numbers
🔣 Symbols
📏 Custom password length
🎲 Random character generation
Requirements
Python 3.1.4
How to Run
Download or clone this repository.
Open the project folder.
Run:
python password_generator.py
Enter the password length when asked.
Example
Password length: 12

The program will generate a random password using letters, numbers, and symbols.
